# Cloth Store Annual Report – Excel Data Analysis Project

An **Excel Data Analysis and Interactive Dashboard project** built to analyze a cloth store's annual sales and order data. The project focuses on data cleaning, data transformation, exploratory analysis, Pivot Tables, charts, and an interactive dashboard using Excel slicers.

## 🎯 Project Objective

The objective of this project is to analyze annual cloth-store sales and order data and generate meaningful business insights related to:

* Sales and order trends
* Monthly performance
* Customer gender distribution
* Order status
* Top-performing states
* Age and gender relationships
* Sales by online channel
* Product/category performance

## 🔄 Project Workflow

### Step 1: Data Cleaning

* Checked the dataset for null/missing values.
* Removed or handled inappropriate values.
* Corrected data types and formatting.
* Standardized the data to make it suitable for analysis.

### Step 2: Data Processing

Created additional columns required for analysis, including:

* **Age Group**
* **Month**
* Other calculated fields required for reporting and analysis.

### Step 3: Data Analysis

Used **Pivot Tables** to analyze sales and order data from different perspectives.

Created charts to visualize:

* Monthly sales and orders
* Sales by gender
* Order status
* State-wise sales
* Age vs. gender order distribution
* Orders by sales channel
* Category performance

### Step 4: Interactive Dashboard

Created an interactive Excel dashboard using:

* Pivot Charts
* Slicers
* Multiple filters
* KPI-oriented visualizations

The dashboard allows users to filter the report by **Category, Month, and Channel** and dynamically explore the data.

---

## 🔎 Business Questions

The project answers the following business questions:

1. How do **sales and orders** compare over time?
2. Which month generated the **highest sales and orders**?
3. Who purchases more — **Men or Women**?
4. What are the different **order statuses**?
5. Which are the **Top 5 states** contributing to sales?
6. What is the relationship between **age group, gender, and number of orders**?
7. Which **online sales channel** contributes the most orders?
8. Which **category** has the highest sales?

## 📈 Key Insights

Based on the dashboard analysis:

### Monthly Performance

* **March** recorded the highest monthly sales and order volume.
* Sales and orders generally show a declining trend toward the end of the year.

### Customer Gender

* **Women contribute approximately 64% of orders**.
* Men contribute approximately **36%**.

### Order Status

* **Delivered orders account for approximately 92%** of total orders.
* Cancelled, refunded, and returned orders represent a relatively small portion.

### Top 5 States by Sales

| Rank | State         | Sales |
| ---- | ------------- | ----: |
| 1    | Maharashtra   | 2.99M |
| 2    | Karnataka     | 2.65M |
| 3    | Uttar Pradesh | 2.10M |
| 4    | Telangana     | 1.71M |
| 5    | Tamil Nadu    | 1.68M |

### Sales Channel

Among the channels shown in the dashboard:

* **Amazon – 35%**
* **Myntra – 23%**
* **Flipkart – 22%**
* Ajio – 6%
* Nalli – 5%
* Meesho – 5%
* Others – 4%

**Amazon is the leading channel**, contributing approximately 35% of orders.

### Age & Gender

The dashboard shows that the **Adult Women** segment contributes the largest share of orders among the displayed age groups.
